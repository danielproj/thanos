# Security policy

Thanos reads file metadata across your disk and can move files to the Trash, so security and safety bugs matter.

## Reporting a vulnerability

Please **do not open a public issue**. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/danielproj/thanos/security/advisories/new).

Include what you found, how to reproduce it, and its impact. You can expect an acknowledgement within a few days.

Also report as a security issue anything that could make Thanos remove files a user did not choose, or remove them without going through the Trash.

## Supported versions

Only the latest release receives fixes.
